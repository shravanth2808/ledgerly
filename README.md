# Ledgerly – Freelancer & Micro-Business Cash-Flow Dashboard

A clean, minimal desktop web dashboard for freelancers and small shop owners to track cash flow, invoices, receipts and estimated tax, without complex accounting software.

**Live demo:** https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/

## Features
- **Analytics dashboard:** income vs. expenses vs. tax holdout chart (May–Dec, with Nov–Dec forecast), KPI cards, expense categories
- **Tax holdout:** adjustable estimated rate applied to net profit
- **Invoices:** quick "New invoice" modal and status tracker (draft, sent, overdue, paid)
- **Receipts:** drag-and-drop scanner UI with category suggestion, and a month-by-month receipt list
- Dark mode, keyboard focus styles, reduced-motion support

## Run locally
Open `index.html` in any modern desktop browser. No build step or dependencies.

## Notes
- All data is sample data held in memory and resets on refresh.
- Receipt scanning is simulated (it reads the filename, not the image).
- Tax holdout is an estimate, not tax advice.

## Tech
HTML, CSS and vanilla JavaScript in a single file. Charts are drawn with inline SVG.

## Design process
Persona and scope, competitor audit (QuickBooks, FreshBooks, Xero), wireframes, design system, hi-fi screens, prototype, usability testing, case study.
